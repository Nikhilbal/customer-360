# Customer 360 Analytics Platform

A data analytics and machine learning platform designed to provide a complete 360-degree view of customers by analyzing customer behavior, segmenting users, and identifying churn patterns using interactive dashboards.

## 🚀 Project Overview

Customer 360 Analytics Platform helps businesses understand their customers better by collecting, processing, and analyzing customer data from multiple touchpoints. The platform uses machine learning techniques to segment customers and generate useful business insights through an interactive Streamlit dashboard.

## 🎯 Key Features

- Customer data cleaning and preprocessing
- Customer segmentation using K-Means Clustering
- Churn behavior analysis
- Interactive analytics dashboard
- Visual insights for business decision-making
- Customer behavior and engagement analysis
- Data-driven customer profiling

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- K-Means Clustering
- Machine Learning
- Streamlit

## 📊 Use Cases

- Customer segmentation
- Churn prediction analysis
- Business intelligence reporting
- Marketing campaign targeting
- Customer behavior understanding
- Decision support for business teams

## 🧠 Machine Learning Approach

The project uses K-Means Clustering to group customers based on similar behavior patterns such as purchase activity, engagement, spending behavior, and churn-related indicators.

## 📌 Why This Project?

Businesses often store customer data across different systems. This platform brings customer information into a unified analytical view, helping teams identify valuable customers, inactive users, and potential churn risks.
